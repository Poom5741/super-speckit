# Third-party notices

Super-SpecKit V2 is new Apache-2.0 code. The V2 packages depend on third-party libraries under their published licenses. Run `pnpm licenses list --prod` from the repository root to produce the installed dependency inventory.

ADE remains an external AGPL peer process. Super-SpecKit does not copy, link, or embed ADE code. Herdr and Cloudflare integrations use their public process and network interfaces.

The existing `vendor/pstack/` tree keeps its own license and provenance files. The V2 package license does not relicense that directory.
