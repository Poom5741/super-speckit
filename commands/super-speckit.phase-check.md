---
description: Check a Spec Kit task slice is ready for isolated execution using a GSD-style phase contract without replacing native artifacts.
---

Create a phase contract from the micro playbook or selected native spec/plan/tasks, the matrix, and repository evidence. Confirm one observable outcome, named requirement IDs, bounded scope, dependencies, lane classification, verification method, and a milestone-audit question. For high-risk or uncertain work, invoke the pinned upstream Matt research/grill/domain skills before approval. Reject or return the phase for refinement if any requirement, owner, evidence method, or blocking decision is absent. Do not begin code changes until the phase contract passes. Use one code-writing owner in the current checkout.
