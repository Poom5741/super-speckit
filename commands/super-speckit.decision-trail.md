---
description: Keep a concise, evidence-bound decision trail for long autonomous work and handoffs.
---

For an autonomous run, material design/implementation/triage decision, or pause, append a row to `decision-trail.md` using the template. Every row names the decision, alternatives, evidence paths or command receipts, reversibility, enforcement/proof, owner/stage, and remaining unknowns. Link real files and immutable SHAs; do not summarize chat memory as evidence.

Record the artifact with `record-artifact <feature> decision-trail`. This is an explanation and recovery aid, not an approval substitute or a source of truth over the YAML/JSON state and proof pack.
