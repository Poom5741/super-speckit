# Baseline feedback loop

The frozen V1 signal is `python3 -m unittest discover -s tests`. The V2 signal is `pnpm check:v2 && pnpm test:v2`. Public-seam fixtures cover installation, daemon reconnection, card revisions, attempts, fencing, handoff, evidence, adoption, provider conformance, native execution, and the persistent WSL bridge. Live provider and cross-platform gates remain explicitly unverified until their real environments are available.
