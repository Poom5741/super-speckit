# Figure-it-out playbook

## Definition of done

The public alpha predicate passes only when AC-01 through AC-12 have exact-candidate evidence. External provider or platform access that is absent is not verified.

## Ordered phases

1. Frame. Preserve V1, quantify the 17 Foundation and 10 Feature cards, and record external blockers.
2. Design the workflow. Build schemas, tests, and the coordinator before provider features.
3. Run the loop. Implement one verifiable card at a time and keep negative fault fixtures.
4. Keep the audit trail. Append material decisions to `docs/v2/implementation-decisions.tsv`.
5. Verify and hand back. Run deterministic gates and distinguish verified code from unavailable live certification.

## Rigor

This is milestone work. Writer authority, cross-machine handoff, secrets, and release evidence are high-blast-radius boundaries. Each boundary needs negative tests before provider integration.
