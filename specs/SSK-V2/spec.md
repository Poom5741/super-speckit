# Super-SpecKit V2 full-ecosystem alpha

Super-SpecKit V2 adds a provider-neutral execution runtime and an OpenCode Mission Control view while preserving V1 and portable delivery. GitHub Issues and Projects own card intent. Repository contracts own technical truth. One elected coordinator owns attempts, writer authority, checkpoints, handoffs, budgets, and evidence.

The alpha requires OpenCode, macOS or Linux, Windows with WSL, Herdr, ADE, Cloudflare Browser Run, existing-project adoption, architecture intelligence, and greenfield Foundation generation. Missing external access remains not verified and blocks the public-alpha claim.

See `design/features/super-speckit-v2/SPEC.draft.md` for the approved detailed acceptance contract and `docs/v2/system-architecture.draft.md` for authority boundaries.
