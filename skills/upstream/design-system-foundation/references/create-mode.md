# Create mode: establish a new visual system

Use when no approved visual system exists and the product context is sufficiently clear.

## Process

1. Read approved product and domain context.
2. Identify category conventions users depend on.
3. Propose at least three coherent directions that differ in visual thesis, not merely colors.
4. For each direction explain safe category choices, deliberate risks, benefits and costs.
5. Apply promising directions to representative artifacts.
6. Obtain human selection or synthesis.
7. Define exact tokens and rationale.
8. Draft and validate `DESIGN.md`.

## Direction proposal requirements

Each direction should state:

- intended emotional response;
- typography roles;
- color strategy;
- density and layout posture;
- shape and surface language;
- motion posture;
- two deliberate differentiators;
- accessibility and implementation risks.

Do not finalize tokens before a direction is selected. Do not use generic AI defaults to fill missing brand decisions.
